# linA-scribe

This repository is documenting the development of a semi-automatic tool meant to trace Linear A signs from low-contrast CEFAEL-style images as part of the Bachelor Project ***Machine Learning for Semi-Automated Annotations of the Linear A Inscriptions*** at DTU. Besides the software segmentation quality evaluation in the `src/` folder, it also includes the LaTex project of the Thesis and the Project Definition Report (PDR) in the `thesis/` and `pdr/` folders, respectively.

The `data/` folder within `src/` is exclusively included locally, as to avoid any Intellectual Property Rights (IPR) issues.
