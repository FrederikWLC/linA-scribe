# linA-scribe

This repository is documenting the development of a semi-automatic tool meant to trace Linear A signs from low-contrast CEFAEL-style images as part of the Bachelor Project ***Machine Learning for Semi-Automated Annotations of the Linear A Inscriptions*** at DTU. Besides the software within the `src/` folder for evaluation of segmentation quality, it also includes the LaTeX project of the Thesis and the Project Definition Report (PDR) in the `thesis/` and `pdr/` folders, respectively.

The `data/` folder within `src/` is now also included here, as to present all (the repository is private, so no Intellectual Property Rights (IPR) issues).
